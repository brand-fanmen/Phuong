# DRAFT: Kết quả chưa duyệt hoặc đang làm dở

> Mọi kết quả **chưa được người dùng duyệt** hoặc **đang làm dở** nằm trong thư mục này.
> Khi người dùng duyệt bản cuối, Trưởng phòng chuyển kết quả sang `output/` (và cập nhật `brand/` nếu người dùng đồng ý).
> Các file trong `draft/` **không phải nguồn chính thức**. Agent không được coi nội dung ở đây là thông tin thương hiệu đã chốt.
